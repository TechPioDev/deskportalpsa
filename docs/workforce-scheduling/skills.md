# Skills

- **The catalogue is the organization's own;** nothing is hard-coded. Workforce managers add, rename,
  describe, retire and reactivate skills.
- **Names are unique per organization,** ignoring case and spacing ("SonicWall" equals " sonicwall "),
  2-80 characters, plain text. Names are always shown as text, never as HTML.
- **A skill is retired, not deleted.** Holders keep it, and nobody new can be given it until it is
  reactivated.
- **Levels:** Basic, Proficient, Expert. They are used to rank who is best suited when work is
  planned (later phases), **never to grade people**.
- **Changing a level** goes through the same call as assigning. Assigning the same skill at the
  same level again is refused.
- **Deferred:** certifications and expiry dates.
